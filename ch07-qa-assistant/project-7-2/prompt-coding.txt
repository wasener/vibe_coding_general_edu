
請幫我使用python程式(flask)開發一個 LLM對話應用程式．
所需要的功能如下：
(1) 呈現方式，banner(生活保健小幫手)/content(chat history)/input box (輸入視窗＋送出按鈕/Shift+Enter).
(2) 建立一個 config.json 檔案來設定程式各項參數. LLM detail info - LLM, model, api-key,content length,..., 請以 gemini LLM 做為預設的設定．
(3) LLM message 請幫我拆分成 "角色定義"、"知識庫”、“規範”、"本次訊息"、"聊天歷史紀錄" 這幾個部分. "聊天歷史紀錄" 為最低優先權，對話視窗長度不夠時，優先裁減歷史紀錄.
(4) 畫面中新增一個 tab 用來編輯項目(3)的內容．
(5) 使用 sqlite3 資料庫模組. 用來儲存對話紀錄, 項目(3)需要儲存的資訊.
(6) 使用亮色系風格畫面, 亮底深色文字, 並且使用 bootstrap 資源.
(7) 輸出程式 project-7-2/run.py, 使用端口 port 8051
(8) 建立 requirements.txt 檔案.

執行程式：
   cd chapter-07/project-7-2
   conda activate health-app
   pip install -r requirements.txt
   python run.py
   開啟瀏覽器： http://127.0.0.1:8051
