

Prompt-01: 建立一個血壓小工具，這次使用 python 的方式製作與第三章功能相同的網站.

請幫我設計一個python程式(flask)，用來紀錄血壓的變化.

所需要的功能如下：
(1) 使用 sqlite3 資料庫模組.
(2) 需要紀錄 量測日期、量測時間、收縮壓、舒張壓、脈搏、備註. 五個欄位.
(3) 需要顯示歷史紀錄功能.
(4) 歷史紀錄需要有查詢功能，可查尋：起始日期、結束日期、最高收縮壓、最低收縮壓、最高舒張壓、最低舒張壓．
(5) 歷史紀錄可以單筆刪除．
(6) 使用亮色系風格畫面, #22713F 淺藍色 + #FFF8F4 暖白色組合
(7) 輸出 requirements.txt 檔案，包含此專案所需的套件．
(8) 輸出程式 project-5-6/run.py, 使用端口 port 8051
(9) 建立 requirements.txt 檔案.


Prompt-02: 新增判定血壓狀態的設定頁面.

請幫調整 project-5-6 專案.
(1) 新增一個 "血壓標準設定“頁面. 用來設定 ”正常血壓“ 、“血壓偏高”、“高血壓一期”、“高血壓二期” 的收縮壓 與 舒張壓 的判定範圍.
(2) 調整歷史紀錄的顯示方式，”正常血壓“底色不變 、“血壓偏高”黃色底色、“高血壓一期”橘色底色、“高血壓二期”紅色底色, 方便快速檢視.
(3) 調整歷史紀錄的顯示方式，在”備註“之後、刪除按鈕之前，顯示血壓狀態.”正常血壓“ 、“血壓偏高”、“高血壓一期”、“高血壓二期”
(4) 血壓標準預設 
   ”正常血壓“ 收縮壓 < 120    舒張壓 < 80
   “血壓偏高” 收縮壓 120 ~ 129  舒張壓 < 80
   “高血壓一期” 收縮壓 130 ~ 139  舒張壓 80 ~ 90
   “高血壓二期” 收縮壓  >= 140  舒張壓 >= 90

執行程式：
   cd chapter-05/project-5-6
   conda activate health-app
   pip install -r requirements.txt
   python run.py
   開啟瀏覽器： http://127.0.0.1:8051

結束程式：
  關閉方式：Ctrl + C 
  如果服務執行時出現 port 8051 筆被佔用，可以刪除佔用的程序 : $ kill $(lsof -ti:8051)
