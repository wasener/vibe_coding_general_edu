狀態  頁面名稱          網頁檔名        開發備註
------------------------------------------------
[ ]   首頁／藥箱清單    index.html      對應 SRS FR-2/FR-3/FR-4、6-1、6-2、§10；顯示所有藥品概況、依 6-2 規則以綠/黃/紅/灰顯示到期狀態，提供分類（眼藥水/內服藥水/外用藥膏/其他）、狀態、關鍵字三種篩選，畫面固定顯示 §10 免責聲明文字與資料最後匯入時間。
[ ]   新增／編輯藥品    add-edit.html   對應 SRS FR-1、FR-6、6-1；表單含藥品名稱、分類、開封日期、開封後保存天數（依 6-1 分類預設值自動帶入，可覆寫）、備註，並提供關鍵字搜尋框，呼叫與 FR-7 相同的查詢邏輯帶入 drug_reference 中的藥品名稱與分類。
[ ]   藥品詳情          detail.html     對應 SRS FR-2、FR-3、FR-5、6-3；顯示單一品項到期日／剩餘天數／顏色標籤，已過期或使用者點擊時依分類顯示 6-3 廢棄處理指引，並提供編輯／刪除連結。
[ ]   藥品查詢          search.html     對應 SRS FR-7、4-4；用名稱／成分／藥商關鍵字查詢 drug_reference，查詢結果僅顯示依 4-4 規則篩選、去重後「目前有效且最新」的一筆，顯示藥品代號、中文名稱、成分、劑型、藥商、支付價、有效起訖日，並可一鍵「加入藥箱」帶入 add-edit.html。
[ ]   資料匯入          import.html     對應 SRS FR-8、4-5；選擇 CSV 檔案（預設可用隨附的 A21030000I-E41001-001.csv）執行匯入，依 4-3 分類篩選＋4-4 有效性與去重規則處理後寫入 drug_reference，完成後顯示新增／更新／下架筆數摘要與「資料最後匯入時間」，並寫入一筆 import_logs 紀錄。
[ ]   關於／資料來源說明 about.html      對應 SRS §8、§10、§11；說明資料來源為衛福部健保署公開資料，並註明有效起日／迄日為健保支付價格生效期間、非保存期限，列出完整免責聲明與 v1 範圍外事項（含「不自動連線健保署平台，需手動下載後匯入」）。

備註：
・本次更新新增「藥品查詢」（search.html）與「資料匯入」（import.html）兩個頁面，對應 SRS 修訂版新增的 FR-7、FR-8。
・新增與編輯共用同一張表單頁（add-edit.html），依是否帶入既有藥品 id 判斷為新增或編輯模式，避免重複開發兩個相似頁面。
・FR-6（add-edit.html 內的搜尋帶入）與 FR-7（search.html 獨立查詢頁）共用同一套查詢邏輯（4-4 有效性與去重規則），開發時建議寫成共用函式，避免兩處邏輯不一致。
・import.html 為資料維運頁面，一般家庭使用情境下多半只有首次使用與健保署公布新版資料時才會用到，UI 設計時可考慮與 about.html 放在同一個「設定／資料管理」入口，降低一般使用者的操作干擾。
・about.html 為 SRS §9 中的可選畫面，但因需固定揭露資料來源、免責聲明與資料最後匯入時間（§10），v1 仍規劃為必要頁面。
・本清單僅列出頁面層級的開發項目；各頁面內部的表單驗證、資料庫存取（medicines／drug_reference／disposal_guides／import_logs）與第 4-3～4-5 節的匯入處理邏輯，開發時請對照 SRS 逐一確認後再將狀態改為 [X]。
